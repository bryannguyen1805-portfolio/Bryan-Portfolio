## 1. Package Contents & Directory Layout

The `03_WORKING_PHASES/PHASE07_R1.0.3/` directory is organized into canonical modules:

- **`01_REPORTS/`**: 16 comprehensive audit and QA reports for R1.0.3, with obsolete reports quarantined under `historical/`.
- **`02_SOURCE_CODE/`**: The complete production and orchestrator codebase:
  - `phase07_daily_runtime_orchestrator.py`: Master 20-step orchestrator.
  - `phase07_dynamic_news_engine.py`: Dynamic news discovery, provenance ledger, deduplication, and fact auditing.
  - `phase07_editorial_intelligence_engine.py`: Genuine dynamic synthesis for theses, dots, chains, radars, and decision cards.
  - `market_pulse_discovery.py` & `phase07_market_pulse_runtime.py`: Market Pulse 8-indicator live discovery and execution runtime.
  - `google_sheets_dry_run_engine.py`: 7-tab Google Sheets reconciliation engine (320 rows).
- **`03_SCHEMAS_AND_CONFIG/`**: Canonical runtime config and Contract V4 / V5 schemas.
- **`04_INTELLIGENCE_OUTPUTS/`**: Intelligence payloads generated by runtime execution.
- **`06_DAILY_EDITIONS/`**: Daily editions repository with isolated `executions/<executionId>/` runs.
- **`07_TESTS/`**: 5 automated test suites with 98 automated tests.

## 2. Standard Operating Procedures (SOP)

### 2.1 Running the Daily Orchestrator (Offline Mode)
```bash
python3 02_SOURCE_CODE/phase07_daily_runtime_orchestrator.py \
  --mode OFFLINE \
  --date 2026-11-10 \
  --edition ED-20261110-D01 \
  --timestamp 2026-11-10T22:30:00+07:00 \
  --exec-id EXEC-20261110-223000-001
```

### 2.2 Running the Full Automated Test Battery (98 Tests)
```bash
python3 -c "
import subprocess, sys
suites = [
    '07_TESTS/test_phase06_intelligence.py',
    '07_TESTS/test_phase07_runtime.py',
    '07_TESTS/test_phase07_r101_remediation.py',
    '07_TESTS/test_phase07_r102_remediation.py',
    '07_TESTS/test_phase07_r103_remediation.py'
]
for s in suites:
    ret = subprocess.run([sys.executable, s]).returncode
    if ret != 0: sys.exit(1)
print('ALL 98 TESTS PASSED!')
"
```
